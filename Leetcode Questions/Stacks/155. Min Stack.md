[155. Min Stack](https://leetcode.com/problems/min-stack/)

Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.

Implement the `MinStack` class:

- `MinStack()` initializes the stack object.
- `void push(int value)` pushes the element `value` onto the stack.
- `void pop()` removes the element on the top of the stack.
- `int top()` gets the top element of the stack.
- `int getMin()` retrieves the minimum element in the stack.

You must implement a solution with `O(1)` time complexity for each function.

# Implementation

A stack is a LIFO based ADT. Can be implemented by using a normal list/array then simply only allow retrieval and insertion on the Nth element of the array where N is the array size. 

We note that with a min stack, we can simply **record** a min variable internally every time a value smaller than min is inserted into stack.

To implement each method (assuming in python):
MinStack() - simply create a empty list
push(int value) - append value to back of list
- If stack empty, record first element as min
pop() - remove the Nth value from stack
- If min was popped, go through entire stack and evaluate new min 
top() - return Nth value from stack
getMin() - simply return the min

---
# Solution
``` python
class MinStack:

    def __init__(self):
        self.stack = []
        #assuming that getMin is only called when stack is non empty, 
        #then we can assume a dummy 0 is fine
        self.min = 0; 

    def push(self, value: int) -> None:
        if (value < self.min or len(self.stack) == 0):
            self.min = value
        self.stack.append(value)

    def pop(self) -> None:
        popped = self.stack.pop()
        #recalculate the min
        if (self.min == popped and len(self.stack) != 0): 
            self.min = self.stack[0]
            for x in self.stack:
                if (x < self.min):
                    self.min = x

    def top(self) -> int:
        return self.stack[len(self.stack) - 1]

    def getMin(self) -> int:
        return self.min
        
```
