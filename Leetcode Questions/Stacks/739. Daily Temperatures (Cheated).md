[739. Daily Temperatures](https://leetcode.com/problems/daily-temperatures/)

Given an array of integers `temperatures` represents the daily temperatures, return _an array_ `answer` _such that_ `answer[i]` _is the number of days you have to wait after the_ `ith` _day to get a warmer temperature_. If there is no future day for which this is possible, keep `answer[i] == 0` instead.

**Example 1:**

**Input:** temperatures = [73,74,75,71,69,72,76,73]
**Output:** [1,1,4,2,1,1,0,0]

**Example 2:**

**Input:** temperatures = [30,40,50,60]
**Output:** [1,1,1,0]

**Example 3:**

**Input:** temperatures = [30,60,90]
**Output:** [1,1,0]

**Constraints:**

- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`


---
# Input/Output

Input:
- List of daily temperatures (where temperatures can be between 30 to 100) and list length is between 1 and 10^5
	- Temp being between 30 and 100 can probably be considered irrelevant
	- Length being between 1 and 10^5 requires something fast (i.e a monotonic stack in increasing order that tracks the index position and index value)

Output:
- A list of same size as input
	- Each list element is the days to which a higher temp occurs
	- If no next higher temp occurs, 0 can be returned 

---
# Basic Implementation

Simple Brute Force Implementation without the use of monotonic stack:
### Pseudo Code
```
daysList = []
For X, index in temperatures:
	if (index != len(temperatures))
		newIndex = index
		daysList[index] = 0 //set to zero by default
		while (newIndex < len(temperatures)) :
			if (temperatures[newIndex] > temperatures[index]):
				daysList[index] = newIndex-index
				break
			else:
				newIndex += 1
	else //last element can just be 0
		- daysList[index] = 0
```

### Explanation
Simply goes through the rest of the array to find a higher temp day. Sets a current daysList[index] to zero if it doesn't exist

### Solution
``` python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        daysList = []
        for idx, x in enumerate(temperatures):
            if (idx != len(temperatures) - 1):
                newIndex = idx
                daysList.append(0)
                while (newIndex < len(temperatures)):
                    if (temperatures[newIndex] > temperatures[idx]):
                        daysList[idx] = (newIndex-idx)
                        break
                    else:
                        newIndex += 1
            else:
                daysList.append(0)

        return daysList
```

### What Goes Wrong
Takes way too long to do this ,as noted in the constraints where:
- 1 <= temperatures.length <= 10^5
Every single time we must iterate through the rest of the array, this results in a overall time complexity of O(n^2) which is too slow given the size constraints

---
# Implementation

We instead now track indexes in a stack:
- if a larger temp of the current tracked index is found compared to the top most stack index
	- We can pop from stack, and now calculate the days to next highest temp for that stack index (latest index - stack index) 
	- This processed is repeated until stack is empty or the newest stack element has a higher temp again
We also note that the stack is monotonic in nature:
- We only ever add stack elements with higher and higher index values

                topIdx = stack.pop()
                daysList[topIdx] = idx - topIdx #go backwards now and set the found lowest days to higher temps
            stack.append(idx) #add the current index into stack for future comparisons
        return daysList
