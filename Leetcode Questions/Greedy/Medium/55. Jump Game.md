# 55. Jump Game

[55. Jump Game](https://leetcode.com/problems/jump-game/)

You are given an integer array `nums`. You are initially positioned at the array's **first index**, and each element in the array represents your maximum jump length at that position.

Return `true` _if you can reach the last index, or_ `false` _otherwise_.

**Example 1:**

**Input:** nums = [2,3,1,1,4]
**Output:** true
**Explanation:** Jump 1 step from index 0 to 1, then 3 steps to the last index.

**Example 2:**

**Input:** nums = [3,2,1,0,4]
**Output:** false
**Explanation:** You will always arrive at index 3 no matter what. Its maximum jump length is 0, which makes it impossible to reach the last index.

**Constraints:**

- `1 <= nums.length <= 104`
- `0 <= nums[i] <= 105`

---
# Input/Output

Input:
- Fixed Order of jumps
		- 10^4 length meaning a close to O(n) is probably preferred (can't brute force)
		- Possible to not reach the end
		- Last element of array does not matter (no more indexes to jump to)
		- NOTE: this was unclear but the number indicates MAX jumps, we can thus take 0 to N jumps forward where N is the max jumps at a given index

Output:
- True if can reach the end
- False otherwise

---
# Implementation/Approach

A greedy approach can be taken for this question instead of DP. We will essentially go backwards, from end to start, and see if we can find continue a chain of jumps to the end:
- This requires tracking the previous known index that can reach the end
- If a jump exceeds or is equal to this index, then we know that we can reach the end at the current index
- We repeat until we get to start of array
- If the last known index to the end is zero (0), then there is at least one combination of jumps to the end.

Another thing to note is that a forward for loop will not work, the local maximum at a given point might just lead to a dead-end or otherwise can't reach the max. In comparison a backwards for loop works because any new "maxNextIndex" we've found previously will allow us to reach the end point, we just have to eventually get the maxNextIndex to 0 (aka. it is possible to find a chain of jumps from start to the end)

# Solution
```python
class Solution:
    def canJump(self, nums: List[int]) -> bool:
        numsBackwards = reversed(nums)
        #print (len(nums))
        #print("---")

        canReachFromIndex = len(nums)-1 #the last known node in the chain that can reach to the end
        #NOTE, every other node/number doesn't matter, it only matters if this last one can be reached at a given moment
        #NOTE at the end of the entire passthrough, if we reach 0, then we know that there is at least 1 chain of jump options that allow for jumping to the end 

        for index, num in enumerate(numsBackwards):
            if (index == 0):
                pass
            else:
                maxNextIndex = (len(nums)-1)-index + num
                if (maxNextIndex >= canReachFromIndex):
                    canReachFromIndex = ((len(nums)-1)-index)
                    #print ("can reach from index: " + str((len(nums)-1)-index))
                #print (str(maxNextIndex) + " " + str((len(nums)-1)-index))

        
        if (canReachFromIndex == 0): #we can indeed get to the end from the start
            return True
        else:
            return False
```
