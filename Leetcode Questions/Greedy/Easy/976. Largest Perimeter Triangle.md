[976. Largest Perimeter Triangle](https://leetcode.com/problems/largest-perimeter-triangle/)

Given an integer array `nums`, return _the largest perimeter of a triangle with a non-zero area, formed from three of these lengths_. If it is impossible to form any triangle of a non-zero area, return `0`.

**Example 1:**

**Input:** nums = [2,1,2]
**Output:** 5
**Explanation:** You can form a triangle with three side lengths: 1, 2, and 2.

**Example 2:**

**Input:** nums = [1,2,1,10]
**Output:** 0
**Explanation:** 
You cannot use the side lengths 1, 1, and 2 to form a triangle.
You cannot use the side lengths 1, 1, and 10 to form a triangle.
You cannot use the side lengths 1, 2, and 10 to form a triangle.
As we cannot use any three side lengths to form a triangle of non-zero area, we return 0.

**Constraints:**

- `3 <= nums.length <= 104`
- `1 <= nums[i] <= 106`



---
# Input/Output
Input:
- Arbitrary list of triangle side lengths 
	- Length of at least 3, always at least one possible option

Output:
- Largest possible valid triangle of Side A + B + C
- 0 otherwise

---
# Implementation/Approach

By property of triangles (i.e if the hypotenuse is smaller than the other 2 sides, then it's a valid triangle)

Thus, greedy approach, sort by max size descending, giving us the best local maximums at every step. also this approach should ensure a single pass since we MUST move on if the next two numbers aren't allowed (no need to predesignate sides or anything to compute a bunch of conditions)

---

# Solution
```python
#by property of triangles (i.e if the hypotenuse is smaller than the other 2 sides, then it's a valid triangle)
#we are finding the LARGEST
#thus, greedy approach, sort by max size descending, giving us the best local maximums at every step
#also this approach should ensure a single pass since we MUST move on if the next two numbers aren't allowed (no need to predesignate sides or anything to compute a bunch of conditions)

class Solution:
    def largestPerimeter(self, nums: List[int]) -> int:
        nums.sort(reverse=True)

        for index,x in enumerate(nums):
            if (index < len(nums) - 2):
                sideC = nums[index+1] + nums[index+2] #adjacent + opposite           
                if (x < sideC):  
                    return x + sideC
        
        return 0 #equivalent of invalid as said by question
```
