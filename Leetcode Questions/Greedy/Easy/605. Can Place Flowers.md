

You have a long flowerbed in which some of the plots are planted, and some are not. However, flowers cannot be planted in **adjacent** plots.

Given an integer array `flowerbed` containing `0`'s and `1`'s, where `0` means empty and `1` means not empty, and an integer `n`, return `true` _if_ `n` _new flowers can be planted in the_ `flowerbed` _without violating the no-adjacent-flowers rule and_ `false` _otherwise_.

**Example 1:**

**Input:** flowerbed = [1,0,0,0,1], n = 1
**Output:** true

**Example 2:**

**Input:** flowerbed = [1,0,0,0,1], n = 2
**Output:** false

**Constraints:**

- `1 <= flowerbed.length <= 2 * 104`
- `flowerbed[i]` is `0` or `1`.
- There are no two adjacent flowers in `flowerbed`.
- `0 <= n <= flowerbed.length`

---
# Input/Output

Input:
- Flowerbed, from length of 0 to alot

Output:
- True if flowers placed >= n
- False otherwise


---
# Implementation/Approach


Greedy implementation as we can simply evaluate in a single pass, where we only require information from the nearest points at any given points.

Simple question, just have to deal with edge cases and what not. Essentially, as long as the current position doesn't have a flower in it and left and rights doesn't have a flower, we can place one.

---
# Solution
``` python
class Solution:
    def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool:
        flowersPlaced = 0
        
        prevFlower = None
        nextFlower = None

        for index, x in enumerate(flowerbed):
            #record the next
            if (index != len(flowerbed) - 1): #if it doesn't violate array
                nextFlower = flowerbed[index + 1]
            #record the prev 
            if (index != 0 and (index - 1) >= 0): #if it doesn't violate array
                prevFlower = flowerbed[index-1]

            #print ("checking pos: " + str(index) + "| next: " + str(nextFlower) + ", prev: " + str(prevFlower))
            #print (flowerbed)
            
            if (x == 0): #cannot add flower if already has one there
                if (#case 1 - main case, applicable anywhere but the edges of flowerbed
                    (prevFlower == 0 and nextFlower == 0) or
                    #case 2 - applicable in the leftmost element
                    (prevFlower == None and nextFlower == 0) or
                    #case 3 - applicable in the rightmost element
                    (prevFlower == 0 and nextFlower == None) or
                    #case 4 - applicable in the constraint case of length = 1
                    (prevFlower == None and nextFlower == None)
                    ):
                    #print ("adding flower")
                    flowerbed[index] = 1
                    flowersPlaced += 1

        #print (flowersPlaced)
        if (flowersPlaced >= n):
            return True
        else:
            return False
```
