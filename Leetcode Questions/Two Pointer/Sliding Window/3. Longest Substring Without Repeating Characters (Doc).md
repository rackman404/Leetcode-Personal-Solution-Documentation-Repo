### Problem:

Given a string `s`, find the length of the **longest** **substring** without duplicate characters.

**Example 1:**

```
Input: s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3. Note that "bca" and "cab" are also correct answers.
```

**Example 2:**

```
Input: s = "bbbbb"
Output: 1
Explanation: The answer is "b", with the length of 1.
```

**Example 3:**

```
Input: s = "pwwkew"
Output: 3
Explanation: The answer is "wke", with the length of 3.
Notice that the answer must be a substring, "pwke" is a subsequence and not a substring.
```

**Constraints:**

- `0 <= s.length <= 5 * 104`
- `s` consists of English letters, digits, symbols and spaces.

### Notes:

- We can use a sliding window technique along with a hashtable
    - define a start and end index, If character doesn’t exist, record in table and expand end index
    - else shrink start index
    - also keep record of max length of start and end index


# Solution
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        table = {}
        substringLen = 0

        leftPtr = 0
        rightPtr = 0
        while (rightPtr < len(s)):
            if (s[rightPtr] not in table):
                table[s[rightPtr]] = s[rightPtr]
                rightPtr += 1
            #elif (s[rightPtr] in table):
            else:
                table.pop(s[leftPtr])
                leftPtr += 1
            
            #temp = rightPtr - leftPtr
            if ((rightPtr - leftPtr) > substringLen):
                substringLen = rightPtr - leftPtr
            #print (table)

        return substringLen
```
