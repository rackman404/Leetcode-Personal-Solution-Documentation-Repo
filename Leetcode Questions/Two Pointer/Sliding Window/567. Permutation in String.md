### Problem:

Given two strings `s1` and `s2`, return `true` if `s2` contains a permutation of `s1`, or `false` otherwise.

In other words, return `true` if one of `s1`'s permutations is the substring of `s2`.

**Example 1:**

```
Input: s1 = "ab", s2 = "eidbaooo"
Output: true
Explanation: s2 contains one permutation of s1 ("ba").
```

**Example 2:**

```
Input: s1 = "ab", s2 = "eidboaoo"
Output: false
```

**Constraints:**

- `1 <= s1.length, s2.length <= 104`
- `s1` and `s2` consist of lowercase English letters.

### Note:

- We can use Hash tables and the sliding window technique
    - Use a immutable “reference” hash table for s1 (as this is the one we are checking to see if s2 contains this or not)
    - Use a “target” hash table which is operated on by the actual sliding window
    - We note this is a fixed sliding window problem (if the windows size ≠s1.length, then obviously it can’t be a permutation
        - Let window size be s1.length

### Solution:
```python
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        windowSize = len(s1) - 1

        refTable = {} 
        targetTable = {}

        for x in s1:
            if (x not in refTable):
                refTable[x] = 1
            else:
                refTable[x] += 1
        
        leftPtr = 0
        rightPtr = 0

        while (rightPtr < len(s2)):

            if (rightPtr - leftPtr != windowSize):
                #print (str(leftPtr) + " " + str(rightPtr) + "Initializing window")
                if (s2[rightPtr] not in targetTable):
                    targetTable[s2[rightPtr]] = 1
                else:
                    targetTable[s2[rightPtr]] += 1    
                rightPtr += 1
            else:
                    if (s2[rightPtr] not in targetTable):
                        targetTable[s2[rightPtr]] = 1
                    else:
                        targetTable[s2[rightPtr]] += 1    
                    rightPtr += 1

                    #print (str(leftPtr) + " " + str(rightPtr))
                    #print (targetTable)
                    #print (refTable)

                    if (refTable == targetTable):
                        return True

                    else:
                        targetTable[s2[leftPtr]] -= 1    
                        if (targetTable[s2[leftPtr]] == 0):
                            targetTable.pop(s2[leftPtr])

                    leftPtr += 1

                    
            
        return False
```
