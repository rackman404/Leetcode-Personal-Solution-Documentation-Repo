
[11. Container With Most Water](https://leetcode.com/problems/container-with-most-water/)

You are given an integer array `height` of length `n`. There are `n` vertical lines drawn such that the two endpoints of the `ith` line are `(i, 0)` and `(i, height[i])`.

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return _the maximum amount of water a container can store_.

**Notice** that you may not slant the container.

**Example 1:**

![](https://s3-lc-upload.s3.amazonaws.com/uploads/2018/07/17/question_11.jpg)

**Input:** height = [1,8,6,2,5,4,8,3,7]
**Output:** 49
**Explanation:** The above vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. In this case, the max area of water (blue section) the container can contain is 49.

**Example 2:**

**Input:** height = [1,1]
**Output:** 1

**Constraints:**

- `n == height.length`
- 2 <= n <= 10^5
- 0 <= height[i] <= 10^4


---
# Input/Output
Input:
- list of heights (and implicitly width's via the index)
	- Height is maxed by 10^4
		- This is very relevant in terms of optimal solving (see below greedy variant)
	- max number of heights is irrelevant (but probably rules out higher time complexities)

Output:
- number where most water possible
---
# Implementation

A brute force implementation could involve a nested double for loop comparing every line after the current line. This would result in a O(n^2) at the worst.

A better solution using Two Pointer:
- We know that a container is limited by the minimum length of both lines
- We can thus have two pointers, starting at either ends of the input set
- We then calculate the max water at each point
- Then move the pointers on either the left or right depending on whichever is higher
	- This follows the logic in first point
- Continue until a valid container is not possible (width becomes 0)

To Calculate Water:
- simple calculation of length X width
- where length is the minimum length of left and right selected lines
- where width is just width line right - width line left (accounts for the moving index pos)
- Can be expressed as:
	- $W=min(l_1,l_2)*(w_2-w_1)$


---
# Solution

``` python
class Solution:

    def maxArea(self, height: List[int]) -> int:
        left = 0
        right = len(height) - 1
        currMaxWater = 0
        
        #while theres still a valid container
        while (left != right):
            temp = min(height[left], height[right]) * (right - left)
            if (currMaxWater < temp):
                currMaxWater = temp
            #left shorter, move it, else move right
            if (height[left] < height[right]):
                left += 1
            else:
                right -= 1
        return currMaxWater
```

### EVEN BETTER IMPLEMENTATION

An even better implementation includes an aspect of greedy algorithms by discarding remaining options when possible.

In this case, we consider the constraint (max height is 10^4), this means that there is a max possible water at each given two pointer combo which is:
	- $MaxWater=10^4*(w_2-w_1)$
If the current Max Water value exceeds the above, then a new highest max water is no longer possible since the width would simply go down more and more.

Results in a greedy implementation as we now terminate early.

### Solution
``` python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left = 0
        right = len(height) - 1
        currMaxWater = 0
        
        #while theres still a valid container
        #ADDITIONAL CONDITION ((10**4) * (right - left)) > currMaxWater)
        #Essentially if we have already reached the max possible water value at the current width,
        #Then we can terminate early (no point in searching anymre)
        while (left != right and ( ((10**4) * (right - left)) > currMaxWater)): 
            temp = min(height[left], height[right]) * (right - left)
            if (currMaxWater < temp):
                currMaxWater = temp
            #left shorter, move it, else move right
            if (height[left] < height[right]): 
                left += 1
            else:
                right -= 1
        return currMaxWater

```
