
### Problem:

Given an array of integers `nums` and an integer `target`, return _indices of the two numbers such that they add up to `target`_.

You may assume that each input would have **_exactly_ one solution**, and you may not use the _same_ element twice.

You can return the answer in any order.

**Example 1:**

```
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].
```

**Example 2:**

```
Input: nums = [3,2,4], target = 6
Output: [1,2]
```

**Example 3:**

```
Input: nums = [3,3], target = 6
Output: [0,1]
```

### Notes:

- Brute force approach would be a O(n^2) whereby for each number in array, we add it up with another number in array and check if it equals target
    - This requires 2 for loops and thus has a quadratic growth rate which would be slow for large input sets
- We note that we are trying to do number1 + number2 = target
    - rearranging this results in target - number1 = number2
    - Could thus record the numbers in a hash table, then for each number, check if number2 exists in the table
        - Would thus be O(n) instead, as both recording to hash table and the single comparison for loop is a O(n) operation and O(n + n) is just O(n)
- Edgecases:
    1. what if same number is used twice (but different indexes)
        1. must use list as the value of key, append to end of list of the index of second instance

### Solution:

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        table = {} #key = num[index], value = index

        for index, x in enumerate(nums):
            if (x not in table):
                table[x] = [index]
            else:
                table[x] = [table[x][0], index] #we do this because we assume there is 1 solution (thus this edgecase would only have 2 same numbers at most)
        #print (table)
        
        for number1 in table:
            number2 = target - number1
            if (number2 == number1):
                if (len(table[number1]) == 2):
                    answer = [table[number1][0], table[number2][1]]
                    return answer
                else:
                    pass
            elif (number2 not in table):
                pass
            else:
                answer = [table[number1][0], table[number2][0]]
                return answer
```

Optimal in time but not memory
