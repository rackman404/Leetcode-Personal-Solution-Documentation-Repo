[36. Valid Sudoku](https://leetcode.com/problems/valid-sudoku/)

Determine if a `9 x 9` Sudoku board is valid. Only the filled cells need to be validated **according to the following rules**:

1. Each row must contain the digits `1-9` without repetition.
2. Each column must contain the digits `1-9` without repetition.
3. Each of the nine `3 x 3` sub-boxes of the grid must contain the digits `1-9` without repetition.

**Note:**

- A Sudoku board (partially filled) could be valid but is not necessarily solvable.
- Only the filled cells need to be validated according to the mentioned rules.

**Explanation:** Same as Example 1, except with the **5** in the top left corner being modified to **8**. Since there are two 8's in the top left 3x3 sub-box, it is invalid.

**Constraints:**

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` is a digit `1-9` or `'.'`.

# Input/Output

Input:
- 9x9 sudoku board
	- represented as a list with 9 lists with 9 elements each

Output:
- True false if valid

# Implementation/Approach

We can just sort of brute force the question. There are 3 criterias in this question:
- Cannot contain 1-9 in:
	- subgrids
	- rows
	- columns
- We may also ignore grid boxes that are empty marked with "."

We can thus maintain a fixed length list of 9 row/col/subgrid dictionaries, then terminate early if we find a collision in the dictionary.

Only trickly part is figuring out the proper subgrid index

Time Complexity = O(n^2)
Space Complexity = O(n)

# Solution
```python
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        #each list is to check row/col/3x3 for duplicate elements, if they do, sudoku is not valid
        #NOTE: assuming constraint of 9x9 board
        hashRow = [{} for i in range(9)] 
        hashCol = [{} for i in range(9)]


        hashSubGrid = [{} for i in range(9)]

        #scan from left to right
        #top to bottom
        
        for rowIndex, row in enumerate(board):
            #print("---")
            for colIndex, element in enumerate(row):
                #print (str(rowIndex) + " " + str(colIndex))
                #check 3 conditions now 
                if (element != "."): #only consider filled cells
                    
                    if (element not in hashCol[colIndex]):
                        hashCol[colIndex][element] = 1 
                    else:
                        #print ("column fail at: " + str(rowIndex) + " " + str(colIndex) + " for: " + element)
                        return False
                    
                
                    if (element not in hashRow[rowIndex]):
                        hashRow[rowIndex][element] = 1 
                        #print (hashRow)
                    else:
                        #print ("row fail at: " + str(rowIndex) + " " + str(colIndex) + " for: " + element)
                        return False

                    #print ("for: " + str(rowIndex+1) + " " + str(colIndex+1) )
                    #print (str((colIndex+1)/3)+ str(ceil((colIndex+1)/3)) + " " + str(floor((rowIndex+1)/3)))
                    
                    #NOTE if else to account for round down at whole numbers
                    #NOTE +1 to emulate 1-9 indexing
                    if (((rowIndex+1)) % 3 != 0):
                        hashRowMultiplier = floor((rowIndex+1)/3)
                    else:
                        hashRowMultiplier = floor((rowIndex+1)/3) - 1
                    #print (hashRowMultiplier)

                    #figure out the subgrid index
                    hashSubGridIndex = (ceil((colIndex+1)/3)+hashRowMultiplier*3) - 1 #NOTE -1 to account for 0-8 indexing
                    #print (hashSubGridIndex)
                    
                    if (element not in hashSubGrid[hashSubGridIndex]):
                        hashSubGrid[hashSubGridIndex][element] = 1 
                    else:
                        #print ("subgrid fail at: " + str(hashSubGridIndex) + " for: " + str(element))
                        return False
                    #print(hashSubGrid)
                
        

        """
        for rowIndex, row in enumerate(board):
            for colIndex, element in enumerate(row):
                #print (element)
                print (str(rowIndex) + " " + str(colIndex))
        """

        return True
```
