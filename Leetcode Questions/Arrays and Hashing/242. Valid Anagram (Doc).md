### Problem:

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.

**Example 1:**

**Input:** s = "anagram", t = "nagaram"

**Output:** true

**Example 2:**

**Input:** s = "rat", t = "car"

**Output:** false

### Notes:

- We may simply check for number of occurrences of each character in a string for both string s and t.
    - We do this to both strings and record to a variable
    - Then simply check if the two have the same characters and occurrences
- Should use a hash table/dictionary for this

### Pseudocode:

1. FUNCTION toDict(string)
    1. dict ← {}
    2. for x in string
        1. if (x not in dict)
            1. dict[x] = 1
        2. else
            1. dict[x] += 1 #record occurrences of this specific character
    3. return dict
2. dict1 ← toDict(s)
3. dict2 ← toDict(t)
4. if dict1 EQUALS dict2
    1. return TRUE
5. else
    1. return FALSE

### Solution:

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        dict1 = toDict(s)
        dict2 = toDict(t)
        
        if (dict1 == dict2):
            return True
        else:
            return False

def toDict(string: str) -> dict:
    dict = {}
    for x in string:
        if (x not in dict):
            dict[x] = 1
        else:
            dict[x] += 1
    return dict
```

Secondary version without using pythons object comparison feature

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        dict1 = toDict(s)
        dict2 = toDict(t)
        
        for x in dict1:
            if (x not in dict2):
                return False
            elif (dict1[x] != dict2[x]):
                return False
        for x in dict2:
            if (x not in dict1):
                return False
            elif (dict2[x] != dict1[x]):
                return False

        return True

def toDict(string: str) -> dict:
    dict = {}
    for x in string:
        if (x not in dict):
            dict[x] = 1
        else:
            dict[x] += 1
    return dict
```
