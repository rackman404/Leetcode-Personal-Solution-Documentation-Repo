
Given a string `s` which consists of lowercase or uppercase letters, return the length of the **longest palindrome** that can be built with those letters.

Letters are **case sensitive**, for example, `"Aa"` is not considered a palindrome.

**Example 1:**

**Input:** s = "abccccdd"
**Output:** 7
**Explanation:** One longest palindrome that can be built is "dccaccd", whose length is 7.

**Example 2:**

**Input:** s = "a"
**Output:** 1
**Explanation:** The longest palindrome that can be built is "a", whose length is 1.

**Constraints:**

- `1 <= s.length <= 2000`
- `s` consists of lowercase **and/or** uppercase English letters only.
---
# Input/Output
Input
- String containing A-Z and a-z letters
Output
- max length of palindrome

# Implementation/Approach

One thing to keep in mind about palindromes:
- A odd letter can be used in the very middle

One thing to keep in mind about this question:
- Does not have to use all or nothing of a given letter
	- In other words, can use some instances of a given letter

We may also note that the letters themselves are irrelevant, only the occurrences of given letters.
As such, we can simply use a dictionary/hash table to process the occurrences of each letter. 

We can then add up the occurrences to the palindrome length in the following cases:
- If Even
	- length += instance letter occurrences
- If odd
	- track the largest odd occurrence 
	- if instance occurrence > largest odd occurrence
		- add previous largest odd occurrence - 1 (remove the odd part)
		- replace largest odd occurrence
	- else
		- just add the instance letter occurrence - 1 (remove the odd part)

Lastly, just add up the largest odd occurrence to the length and return it

# Solution
```python
#if there are even occurances of a given letter, they can be used in the palindrome
#if there are odd occurances of a given letter, the largest amount of odd occurances for a given letter can be used in the palindrome (i.e in the middle and in left and right)

#Didn't realize this but we may use some occurances of a given letter (originally thought we can only use all or no occurances of a given letter)
class Solution:
    def longestPalindrome(self, s: str) -> int:
        hash = {}

        #preprocess (find occurances)
        for x in s:
            if (x in hash):
                hash[x] += 1
            else:
                hash[x] = 1

        palindromeLength = 0
        largestOdd = 0
        if (len(hash.values()) == 1): #if input set is just 1 letter
            return hash[s[0]]

        #single passthrough to find palindrome length
        for x in hash.values():
            if (x % 2 == 0): #check if even
                palindromeLength += x
            else:
                #round back to even, discard the remaining odd instance, 
                #if > largestOdd, then we also replace it
                if (x > largestOdd): 
                    palindromeLength += max(largestOdd-1, 0) 
                    largestOdd = x
                else: 
                    palindromeLength += x-1
            print (palindromeLength)

        return palindromeLength + largestOdd
```

### Marginally faster/less complicated

We note that we can simply just always strip the odd occurrence of a letter out, then simply add one right at the end 
``` python
#if there are even occurances of a given letter, they can be used in the palindrome
#if there are odd occurances of a given letter, the largest amount of odd occurances for a given letter can be used in the palindrome (i.e in the middle and in left and right)

class Solution:
    def longestPalindrome(self, s: str) -> int:
        hash = {}

        #preprocess (find occurances)
        for x in s:
            if (x in hash):
                hash[x] += 1
            else:
                hash[x] = 1

        palindromeLength = 0
        foundOdd = False
        if (len(hash.values()) == 1): #if input set is just 1 letter
            return hash[s[0]]

        #single passthrough to find palindrome length
        for x in hash.values():
            if (x % 2 == 0): #check if even
                palindromeLength += x
            else:
                foundOdd = True
                palindromeLength += x - 1
            #print (palindromeLength)

        return palindromeLength + 1 if foundOdd else palindromeLength
```

### Time Complexity

overall: O(n)

### Greedy
Is greedy because instead of the brute force method where we check if all permutations of the letters given are palindromes or not, we instead:
- pre-process the data by counting occurrences of letters
- Performing a single pass, where at each letter, we are only concerned about its odd or even property
