### Problem:

Given an integer array `nums`, return `true` if any value appears **at least twice** in the array, and return `false` if every element is distinct.

### Notes:

- Use of a hash table/dict would be the most efficient way of checking duplicate
    - if the key (where key is the number being compared) already exists, we know there is a duplicate

### Pseudocode:

1. hash_table ← {}
2. for x in nums
    1. if x not in hash_table
        1. do hash_table[x] ← x
    2. else
        1. return true
3. return false

### Solution:

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        hash_table = {}
        for x in nums:
            if (x not in hash_table): #if duplicate in table
                hash_table[x] = x
            else:
                return True
        return False
        
```
