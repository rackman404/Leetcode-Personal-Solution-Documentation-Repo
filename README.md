
Organized solutions to Leetcode problems I've done, never actually properly organized or documented techniques used before this point. Divided into the following folders (Some stuff might be empty out of laziness):
### Theory
Does not include more in depth stuff (i.e like how a specific Data Structure are implemented) if it doesn't really matter for general problem solving. Some stuff taken straight from "Techniques for Designing and Analyzing Algorithms, Douglas R. Stinson"

### Leetcode Questions
Nothing is formally explained or anything, just basic explanations and approaches that I made to questions. Questions categorized into the main technique/ADT needed to solve it, then further categorized by Leetcode difficulty

NOTE: if the same question is solved in different ways, il put the same question in different folders

(Redo) = bad solution/doesn't use intended approach
